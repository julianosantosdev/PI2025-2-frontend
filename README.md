# SafePlay – Frontend

SafePlay é uma aplicação web desenvolvida em **React + Vite** que permite visualizar jogos, pesquisar títulos, acessar detalhes e realizar autenticação de usuários.  
O projeto faz parte do Projeto Integrador da FATEC Araras.

### OBS: o projeto conta com backend que deverá estar rodando simultaneamente.
https://github.com/Rapha-Reiis/projeto-integrador-4-semestre-backend/tree/main

---

## 🚀 Tecnologias Utilizadas

- React
- Vite
- TypeScript
- Stitches (CSS-in-JS)
- Axios
- React Router DOM
- Integração com backend Node.js
- Integração com API RAWG (via backend)

---

## 📦 Instalação e Execução

### 🔧 Pré-requisitos

Certifique-se de ter instalado:

- Node.js 18+
- npm

Verifique suas versões:

```bash
node -v
npm -v
```
<br>

## 📁 Clonar o Repositório
``
git clone git@github.com:julianosantosdev/PI2025-2-frontend.git
``

Entrar na pasta safezoneplay
``` 
cd safezoneplay
```

## 📦 Instalar Dependências
```
npm install
```

## ▶️ Rodar o Projeto em Desenvolvimento
```
npm run dev
```

O projeto ficará disponível em:
http://localhost:5173
